## Подтверждённые интерфейсные решения
- crm/store.py OUTCOMES: **«Не взял трубку»**, **«Перезвонить»**, **«Отказ»**. «Не дозвонились» встречается в списках/тостах, но не является подписью кнопки итога.
- crm/static/work.js: no_answer сохраняется сразу; callback/отказ открывают форму. У перезвона дата/время/комментарий, у отказа нет даты.
- crm/static/calls.js: менеджер у директора, период/поиск в звонках; перезвоны — группы «Просрочено», «Сегодня», «Дальше». Отдельного фильтра «Просроченные» нет.
- Кнопка «Позвонить» у задачи сначала открывает карточку номера. В учебной учётке используется эта же кнопка «Позвонить»: открывается карточка, настоящая телефония отключена.
- crm/static/deals.js: следующий шаг можно записать через **«Заметка»**. Отдельного поля «Следующий шаг» для ручного редактирования в этой версии нет.
- crm/static/contracts/generator.js: **«Скачать договор (.docx)»** одновременно выдаёт номер и регистрирует документ. В учебной учётке — встроенный учебный документ и локальный журнал; скачивание и внешний поиск не нужны.
- crm/static/more.js: меню **«Отчёты»**, датированная лента без фильтра периода. Уроки выбирают отчёт по заголовку/датам.
- crm/static/summary.js: **«Сегодня», «7 дней», «30 дней», «Месяц»**, показатель **«Разговоров с результатом»**.
- crm/static/people.js: **«Сотрудники» → сотрудник → «Обзор»**, примеры звонков. Карточка менеджера отдельно также доступна в «Моя карточка».
- crm/company.py: contracts/automations/robot проверяются по включённым модулям. Клиентская роль обучения не получает.
- В директорской экскурсии отсутствующие robot/automations явно пропускаются; обязательные staff/settings/access не засчитываются без доступного целевого элемента.

## Адаптации
- m3: Следующий шаг фиксируется через существующую «Заметка», а не через выдуманный статус.
- m4: В рабочем процессе «Скачать договор (.docx)» одновременно регистрирует договор. В упражнении — встроенный учебный просмотр без скачивания, рабочего номера и DaData.
- m5: Период выбирается в журнале звонков. В ленте отчётов — нужная дата/период заголовка без несуществующего фильтра.
- d3: Используется имеющийся переход из «Позвонить» в карточку/историю. Упражнение никогда не набирает номер.
- d5: В отчётах нет фильтра дат. Сначала выбирается датированный отчёт, затем «Сотрудники» и доступный пример из карточки.
- d6: Отключённые модули пропускаются с явным пояснением. Пройдено — после просмотра всех доступных шагов.
