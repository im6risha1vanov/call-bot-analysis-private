# GIF-примеры в справке — 5 ноября 2026

Подготовлено на стенде `/tmp/averon-crm-learning-20261104`, ветка
`feat/crm-help-examples-20261105`, исходная ревизия `f19a0eb`.
Рабочая CRM, данные и службы не менялись.

Кнопка «Справка» в углу текущей вкладки открывает прежнюю правую панель.
Рядом с соответствующими пояснениями теперь показаны те же локальные GIF,
что используются в обучении. Новых копий медиа, запросов к моделям и
рабочих операций нет.

| Вкладка | Примеры |
|---|---|
| Очередь | Выбор клиента, недозвон, дата/время/комментарий перезвона |
| Перезвоны | Перенос той же задачи, открытие истории |
| Сделки | Карточка, заметка о следующем шаге, фильтр зависших |
| Договоры | Переход из сделки, учебные реквизиты, журнал |
| Звонки | Период, менеджер у директора, открытие разбора |
| Сводка директора | Переключатели периода и сотрудника |
| Сотрудники | Карточка и подтверждающий пример |
| Отчёты | Личный итог у менеджера, недельная сводка у директора |
| Настройки | Вкладка доступов без изменения прав |
| Автоматизации / Робот | Переход в доступный раздел без запуска |
| Обучение | Программа и пример заполнения учебной формы |

Для вкладок без соответствующего готового примера остаётся текстовая справка.
Не добавлены чужие или неподходящие GIF ради заполнения каждого раздела.

Каждый пример имеет собственную кнопку «Приостановить пример» / «Включить
пример». Она переключает только изображение рядом с ней. Галочка, текущий
шаг, черновики и GIF в карточке урока не изменяются. При системном уменьшении
движения сначала показывается статичный PNG; пользователь может включить GIF.
Изображения подгружаются лениво, масштабируются по ширине панели, текст и
кнопки переносятся. Учебные значения подписаны; пример договора явно относится
к учебному режиму. Рабочие сроки/реквизиты берут из своей задачи.

Изменены `crm/static/help.js`, `crm/static/helper.css`, версии этих ресурсов
в `crm/static/index.html`, тесты и документация. Сами 41 GIF и 41 PNG,
реестр примеров, сборщик, уроки и серверный код не менялись.
