# Обновление личных задач Telegram

Пакет готовится из проверенной версии файлов, перечисленных в `scripts/deploy_personal_telegram.py` в `FILES`. В каталоге пакета разместите их под `files/` с сохранением путей; `manifest.json` содержит объект из путей и SHA-256 каждого файла. SHA-256 самого manifest передаётся отдельно в `--manifest-sha256`.

Скрипт принимает только заранее проверенную базу `0ea2515ce9f6c196238042f15a96813b31467c47`, ожидаемые сервисы и явно указанный `--apply`. Он сохраняет резервные копии, применяет добавочную миграцию, обновляет настройки только основного бота, перезапускает CRM и основного бота, затем проверяет сервисы, CRM и успешный опрос Telegram в текущем запуске бота. При ошибке он возвращает файлы и настройки из резервной копии; добавленные таблицы миграции остаются в базе.

Не запускать до проверки тестов, состава пакета, контрольной суммы и результата предварительной проверки текущего состояния сервера.

## Возможности и границы

В основном боте доступно меню личных задач для двух участников пилота: список с перелистыванием, создание, изменение названия, статуса, даты, срока, результата и препятствий. Задачи и история общие с CRM; изменения в открытом личном разделе CRM подгружаются автоматически. Доставка напоминаний и голосовой ввод задач в этом выпуске не подключены. Доступ проверяется по личному чату, активному сотруднику, действующему приглашению и списку участников. При первом входе профиль создаётся, если его ещё нет; существующий профиль не перезаписывается.

После установки read-only проверка запускается из каталога приложения через CRM Python: `sudo /opt/averon-crm-venvs/699c50b/bin/python scripts/check_personal_telegram.py`. Она проверяет список в окружении работающего основного бота, таблицы и права базы, доступ обоих участников и наличие их профилей. Она не создаёт профиль, не изменяет данные и не отправляет сообщения. Проверка не заменяет реальный пользовательский сценарий в Telegram.

До установки прошли 130 общих тестов, 35 целевых тестов и 7 финальных изолированных Telegram-сценариев. Обновление CRM и конфликт версии также проверены в браузере на синтетических данных. Проверки не являются подтверждением того, что оба участника уже опробовали функцию в реальном чате.
