# Личный агент — первая версия

Раздел CRM хранит профиль, проекты и задачи отдельно для каждого участника пилота. Доступ разрешается только при совпадении действующего приглашения и сотрудника, отсутствии тестового и support-входа и наличии Telegram ID в `CRM_PERSONAL_PILOT_TELEGRAM_IDS`. Пустое или некорректное значение закрывает доступ. Идентификатор приглашения не используется как идентификатор личного профиля, поэтому несколько действующих способов входа одного человека ведут к одному профилю.

Миграция: `migrations/045_crm_personal_agent.sql`. Настройка: список числовых Telegram ID через запятую; реальные значения назначаются отдельно после проверки. 16 ноября 2026 года миграция 045 и CRM-only настройка пилота применены на production; отдельные процессы бота не перезапускались.

API: `GET/PUT /api/personal/profile`, `GET/POST /api/personal/projects`, `GET/POST /api/personal/tasks`, `PATCH /api/personal/tasks/{id}`, `GET /api/personal/tasks/{id}/history`. Для изменения задачи требуется её `version`; при конкурирующем изменении возвращается 409. Сохранение новой версии и записи истории выполняется одной транзакцией. Отмена и возвращение задач выполняются изменением статуса. Даты срока, запланированного дня и напоминания хранятся отдельно. Доставка напоминаний не реализована.

Время срока и напоминания на экране вводится в часовом поясе устройства; день «Мой день» рассчитывается по часовому поясу профиля. Для обмена API моменты времени передаются с указанием смещения. Приложение не отправляет сообщения и не вызывает модель ИИ.

Тесты: `python -m unittest tests.test_crm_personal -v`. Для HTTP-тестов необходима изолированная PostgreSQL с `METHODOLOGY_TEST_DATABASE_URL`, имя которой начинается на `callbot_methodology_test_`. Сценарий `scripts/personal_preview.py` предназначен только для отдельной тестовой БД с префиксом `callbot_methodology_test_personal_`, открывает 127.0.0.1:8098 и создаёт две синтетические учётные записи.

После выпуска проверены доступность CRM по HTTPS (200), закрытие личного API без входа (401), активное состояние CRM и четырёх процессов Astra. Резервная копия исходных файлов и окружения: `/var/backups/callbot-personal-agent/20261116T183036609214Z`. Проверка реального пользовательского входа после выпуска ещё не заявлена.
