# Отключение курса в анализе звонков — 6 октября 2026

По просьбе владельца отключены `methodology/config.json: mode=legacy` и
`automatic/config.json: enabled=false`. Резервная копия обоих файлов и
`unified/reanalysis.py` находится в
`docs/.rollback/disable-course-20261006T194916Z`.

Оба переключателя читаются заново при обработке. Для новых автоматических
звонков остаются исходный `prompt_score.md`, веса и правила вердикта из
`analysis.py`. Новый запуск не ставит задания оценки по курсу или
дополнительного объединённого анализа. Формат одного сообщения с кнопкой
«Расширенный обзор» сохраняется. Отключение дополнительных вычислений не
означает отключение телефонии или основной обработки звонков.

Старые результаты, версии и кнопки сохранённых разборов остаются доступными.
Задания курса, уже находящиеся в очереди, до нового платного запроса
откладываются существующим обработчиком; они не удалены. Запрос, уже
отправленный провайдеру до переключения, этим изменением не отменяется.
Подготовленные ранее запуски отчётов используют свои закреплённые данные.

Переключатель режима общий для курса и тренажёра. Поэтому новые тренировки
перейдут к существующим исходным сценариям, а незавершённая тренировка курса
может попросить завершить её. Активные сессии в базе не изменялись;
их наличие проверить не удалось. Это следует учесть при последующем
разделении переключателей звонков и тренажёра.

## Исправление ручного нового разбора

`unified/reanalysis.py` теперь закрепляет список этапов нового запуска.
При отключённых дополнениях сохраняется только исходная оценка, без
обращений к пакету курса. Повтор готового запуска использует результат.
Для старого незавершённого запуска отключение также запрещает новый
платный запрос объединённого этапа. Уже полученные результаты сохраняются.
Отдельный явно запрашиваемый эксперимент сравнения А/Б не изменён.

**Это исправление кода подготовлено, но работающий процесс его ещё не
перечитал.** В данной среде systemd недоступен. Для загрузки этого и ранее
подготовленного изменения расширенного обзора потребуется перезапуск
только `callbot-astra.service` из среды с доступом к systemd.

Пробный расширенный обзор строится из сохранённого исходного анализа
последнего подходящего звонка только того клиента, к которому привязан
владелец `@im6risha1vanov`. Получатель повторно проверяется через Actor.
Дополнительные оценки курса не включаются; старые записи не переписываются.
Сохраняются новый снимок для просмотра, кэш обзора и квитанции доставки.
Новых платных запросов к моделям, миграций, массовых сообщений нет.

Повтор исполнения использует тот же снимок с ключом

### Проба на звонке от шести минут

По следующему запросу владельца добавлен `--min-duration 360`.
Выбирается последний уже разобранный звонок длительностью **не меньше**
360 секунд внутри его клиента. Для этого отбора свой ключ сохранённого
просмотра, поэтому предыдущая проба короткого звонка не подставится.
Неподходящие и неоценённые звонки исключаются. Проверка условия времени,
границы 360 секунд, порядка выбора, клиента и отдельного ключа проведена
на вымышленных данных. Итоговый набор — 93 проверки.

```powershell
ssh root@201.51.10.59 "cd /opt/callbot-astra && .venv/bin/python -m scripts.deploy_legacy_preview --apply --restart --min-duration 360"
```

В ограниченной сессии поиск реального звонка и отправка не выполнены:
повторная проверка вновь показала `PermissionError` при чтении `.env`.

### Повторное открытие уже отправленного обзора

После сообщения пользователя «Этот обзор уже отправлен выше. Закройте его
кнопкой, чтобы открыть заново» подготовлено исправление этого неудобного
состояния. Вместо требования удаления показывается кнопка «Показать обзор
здесь». Уведомление отвечает на первую часть сохранённого обзора; если
прежнее сообщение удалено, новая кнопка всё равно позволяет открыть текст.

Повторное открытие только по явному действию использует сохранённый кэш,
архивирует прежние квитанции и создаёт новую последовательную версию
доставки. Двойной клик одной кнопки может создать только одну такую версию.
Устаревшая кнопка не сбрасывает текущую отправку. Неизвестные и частичные
результаты не разрешают повторную рассылку уже отправленных частей.
Старый балл, транскрипт, методики, текст кэша и прежние сообщения не меняются.

В скрипт добавлен `--reopen` для явного повторного просмотра ранее
отправленной пробы. Итоговый изолированный запуск — 98 проверок. Доступ к
systemd и `.env` в текущем сеансе по-прежнему закрыт, поэтому исправление
здесь не загружено в производственный процесс и сообщение не переслано.

```powershell
ssh root@201.51.10.59 "cd /opt/callbot-astra && .venv/bin/python -m scripts.deploy_legacy_preview --apply --restart --min-duration 360 --reopen"
```
