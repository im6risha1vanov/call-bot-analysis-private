## Что подтвердилось по коду и воспроизведено

| Ошибка | Причина | Исправление |
|---|---|---|
| В просмотре невозможно выполнить предложенное сохранение | Показ М1/М2 переходил на обычную очередь CRM, где readonly скрывает итоги; стенд вдобавок блокировал все записи, но раньше представлялся редактируемым | Выбор практического урока сразу открывает изолированное упражнение. Показ при readonly остаётся в учебном экране, выделяет контролы, не выполняет действия. Стенд честно объявляет readonly для рабочих экранов |
| После выполнения виден старый статус | Родитель сохранял сообщения iframe, но не обновлял собственный индикатор | Статус обновляется после сохранения, программа показывает число завершённых уроков |
| Выход снова открывает тот же урок | Сообщение exit и Esc переходили на learning с тем же lesson id | Выход из упражнения, закрытие и Esc возвращают в каталог; попытка сохраняется |

До исправления новый тест с настоящими контроллерами родителя и iframe дал три
ошибки: переход из readonly в рабочий экран, устаревший статус/возврат М1 и М2.
Сводка до/после сохранена в `CRM_LEARNING_CHECKS.json`. Старый тест проверял
учебный контроллер отдельно, поэтому эти ошибки родительской страницы пропустил.

## Проверенные пользовательские пути

| Урок | Действия | Результат автоматической проверки |
|---|---|---|
| М1 | Открыть урок → выбрать УЧ-001 → «Не взял трубку» → проверить историю → вернуться к программе | Пройден; неверный клиент и «Отказ» не засчитываются; общий статус и счётчик обновляются |
| М2 | УЧ-001 → «Перезвонить» → дата/время/комментарий → найти задачу → перенести ту же задачу → проверить результат | Пройден; неправильное время не засчитывается; одна задача, комментарий и исходный срок сохранены |
| М1, М2 | Выход и повторное открытие; обновление контекста; чистый повтор | Шаг/черновик сохраняются; после полуночи срок начатой попытки не меняется; повтор не наследует завершение |
| М1, М2 | Подсветка без выполнения действия | Шаг не засчитывается автоматически |
| Все 10 практик | readonly → урок → действия → завершение → каталог | Все 10 завершены в модели взаимодействия страницы и iframe; рабочих API нет |

Менеджер в этом прогоне завершил 5 из 5. Директор — 5 практик из 6 уроков;
экскурсия Д6 в этот полный родительский прогон не включена. Отдельные старые
проверки логики Д6 (5 шагов/возобновление/отсутствие цели) также прошли.

Выполнены 36 Python-тестов, 22 сценария родителя/iframe в Node, прежние

Рабочие формы, AveronGPT и прежняя экскурсия проверены существующими pure-тестами
и сравнением исходников, без изменения их функциональной логики.

## Ограничения проверки

Это запуск настоящего JS-кода в VM с DOM/event-адаптером, а не браузерный E2E.
Не проверены реальная загрузка iframe, применение CSP браузером, desktop/mobile
вёрстка и управление фокусом в настоящем браузере: браузер отсутствует,
локальный listener запрещён окружением. Изоляция не ослаблена ради прохождения
урока: sandbox/CSP и блокировка рабочих записей сохранены.

Проверки теперь запускаются общим `scripts/check_crm_learning.py`; требуется Node
в PATH или `CRM_LEARNING_NODE`. Инструкция запуска стенда и оставшийся browser
gate — в `CRM_LEARNING.md`. Выкладка не выполнялась и требует отдельной команды;
для полного функционального релиза необходимо сначала пройти browser gate.
Миграций и изменений настроек нет. Откат исправлений — отдельный revert fix-commit
в подготовленной release-ветке, без переписывания истории.
